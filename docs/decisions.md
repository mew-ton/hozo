## 決めたが、まだ文書と実装に入れていないこと

サンプル（`tests/samples/README.md`）を書きながら決めたこと。決定を当てはめた目標の形は、サンプル `tests/samples/shop-server/`（仕様と、手で書いた期待する出力）。ほかの文書と実装は、まだ今の形のまま。入れるときに、この節から「決めたこと」か「設計書を変える決定」へ移し、持ち主の文書を決める。きっかけは、サンプル `shop-server` の「分かったこと」25（人が書く葉の op が、保存先のトランスパイラの API に縛られる）。
