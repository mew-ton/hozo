# 決定の記録

## この文書が決めること

設計書（`mew-ton/drafts` の `hozo/README.md`）が決めていないことについて、実装のためにこのリポジトリで決めたことの一覧と、設計書の内容を変える決定、設計書へ返すこと、今のスコープから外した設計書の例。決定の中身と理由の持ち主は「持ち主」の列の文書と見出し。設計書が決めれば、その項目は消して設計書を引く。
